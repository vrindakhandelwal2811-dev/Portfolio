# Vrinda Khandelwal | Portfolio

A responsive personal portfolio and resume website for Vrinda Khandelwal, Computer Science Engineering student.

## Highlights

- Personal profile hero with responsive layout
- Projects, education, experience, skills, certificates, and achievements
- Light green, light pink, and black visual theme
- Light and night modes with accessible contrast
- Project filtering by status
- Smooth section navigation and reveal animations
- Clickable contact and LinkedIn links
- Downloadable PDF resume
- Responsive design for desktop and mobile

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome
- Google Fonts

## Run Locally

Open `vrinda.html` directly in a browser, or use the Live Server extension in VS Code.
