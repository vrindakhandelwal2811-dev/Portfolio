# Vrinda Khandelwal | Portfolio

A responsive personal portfolio and resume website for Vrinda Khandelwal, Computer Science Engineering student.

## Features

- Responsive portfolio layout for laptop, tablet, and mobile screens
- Profile photo and downloadable PDF resume
- Projects, education, experience, skills, certificates, and achievements
- Light green, light pink, and black visual theme
- Light and night modes with readable contrast
- Project filtering, smooth section navigation, and reveal animations
- Clickable email, phone, and LinkedIn contact links

## Project Structure

```text
Portfolio/
|-- vrinda.html
|-- style.css
|-- script.js
|-- profile.jpg
|-- Vrinda_Khandelwal_FlowCV_Resume_2026-09-28.pdf
`-- README.md
```

`vrinda.html` contains the page structure, `style.css` contains the responsive visual system, and `script.js` contains theme switching, project filtering, printing, and reveal animations.

## Privacy Before Publishing

This is a public portfolio repository. Only publish information you are comfortable sharing publicly. A professional profile photo, LinkedIn profile, email address, phone number, resume, education, and project details are common portfolio content, but remove anything sensitive that you do not want indexed by search engines.

## Run Locally

Open `vrinda.html` directly in a browser, or use the Live Server extension in VS Code.

## Publish With GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages**.
3. Choose **Deploy from a branch**.
4. Select the `master` branch and the `/ (root)` folder.
5. Click **Save**.
